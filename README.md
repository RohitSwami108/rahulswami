## 🚀 Running the Project

### Development Server
```bash
npx ng serve --port 4250
```
Open [http://localhost:4250](http://localhost:4250) in your browser.

### Production Build
```bash
npm run build
```
Output generated in `dist/rahul-portfolio/browser/`.
