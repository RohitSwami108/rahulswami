## 🖤 Design Philosophy & Aesthetic (Inspired by Filmmaker & Quynh.moe)

1. **Monochrome Editorial Palette**:
   - Deep near-black background (`#070707`)
   - Crisp white typography with tight tracking (`-0.035em`)
   - Subdued editorial greys (`#a1a1aa`, `#71717a`)
   - Minimalist hairline borders (`1px solid rgba(255, 255, 255, 0.08)`)
   - Replaced heavy gold gradients with high-fashion typography and expansive visual framing.

2. **Typography**:
   - **Inter**: Bold, tight-tracked grotesque headlines with confident editorial presence.
   - **JetBrains Mono**: For metadata, indices (`[01 // SELECTED WORKS]`), years, coordinates, and camera specs.

3. **Cinematic Hero**:
   - Bold opening statement: *"Spaces rendered with photographic discipline."*
   - Real-time local clock: `● 23:55 IST · New Delhi`
   - Large cinematic featured spotlight switching across 4 signature suites.

4. **Curated Works (Large Editorial Cards)**:
   - Clean metadata headers (`[01] THE OPULENT ARCHED LIVING LOUNGE · 2025`).
   - Expansive 16:10 render photography with smooth hover interactions.
   - Clean case study lightbox featuring high-res multi-angle views, material checklists, and camera parameters.

5. **Complete 50-Render Interactive Archive Vault**:
   - Flip through all 50 renders (`page-01.jpg` to `page-50.jpg`) in full resolution with thumbnail quick-jump and arrow keys.
   - Categorized by space: *Living & TV*, *Bedrooms*, *Modular Kitchens*, *Wardrobes & Vanities*, *Villa Facades*, *Staircase & Foyers*, *Home Offices*.

6. **Interactive 2D Drafting vs 3D Render Studio**:
   - Sleek architectural comparison slider comparing technical AutoCAD 2D drafting against the final 4K Corona photorealistic render.

7. **Studio Practice & Capabilities**:
   - Inspired by Quynh.moe's `/about`:
   - Studio timeline for **Camara Interiors** (Sector 63, Noida) and **Ettore Interior** (Delhi).
   - Software tools arsenal (`3ds Max`, `Corona Renderer 11`, `AutoCAD 2025`, `Photoshop`).
   - Education credentials and core design capabilities.

8. **Direct Collaboration & Contact**:
   - Callout: *"Let's collaborate on your next space."*
   - Instant WhatsApp, direct email, and direct resume download.

## 🚀 Running the Project

### Development Server
```bash
npx ng serve --port 4250
```
Open [http://localhost:4250](http://localhost:4250) in your browser.

### Production Build
```bash
npm run build
```
Output generated in `dist/rahul-portfolio/browser/`.
